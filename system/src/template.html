    How the model works

    8-neighbour Dijkstra search on the native 20 m DEM using Mars-sphere geodesic edge lengths; no diagonal corner-cutting, no interpolation across nodata.

    Walking time uses the slope-dependent Tobler (1993) hiking function normalised to your flat speed: v = v₀·e^(−3.5(|g+0.05|−0.05)). It is an Earth hiking heuristic — not validated for pressurised suits or Mars gravity — and stands in for a suit-specific metabolic model.

    Terrain-penalised cost is d·(1 + w·(Δz/d)²), retained from the M2 engine.

    Integrity checksums

    Products are derived from the cited datasets by the MARSWALK pipeline (see repository). Nothing in this file is a live measurement, forecast or certification of safety.

    Plan a Marswalk in four steps

    1. Set a start — choose Set start and click inside the dashed terrain boundary (habitat or lander).
    2. Add science stops — click mapped crater points, use Add stop, or pick from the list. Three or more make a full traverse.
    3. Plan traverse — the planner finds the fastest order and path while treating red slope cells and reported obstructions as impassable.
    4. Go to the field — open Visor HUD and play the traverse in 2D or the 3D astronaut view. Mark an obstruction at any time and the route recalculates instantly.

    Keyboard: I inspect · S start · W add stop · O obstruction · H HUD · F fit · arrows pan · +/− zoom.

    All measurements come from NASA/USGS orbital and rover products. Times, reserves and slope limits are your stated assumptions — this is a planning demonstrator, not flight software.
